# Seguranca

Este repositorio nao deve conter tokens, cookies do TikTok, senhas ou arquivos de video. Segredos pertencem exclusivamente ao cofre do GitHub Actions e ao ambiente protegido do NovaK Reels.

Se um segredo aparecer em commit, log, issue ou print, ele deve ser revogado e substituido. Nao abra uma issue publica com o valor exposto.

O importador deve ser usado somente com videos proprios, licenciados, autorizados ou em dominio publico. Remover uma marca-d'agua nao altera os direitos sobre o conteudo.
